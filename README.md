# Mobile Game Playbook

Публичная база заметок о мобильных играх: идеи, разборы механик и рыночная аналитика. Основной фокус — Android и адаптация проверенных игровых подходов для РФ/СНГ. iOS и западные рынки используются как источники сигналов, а не как прямой прогноз.

| Раздел | Что сохранять |
| --- | --- |
| [Идеи](ideas/) | Гипотезы, варианты MVP и критерии go/no-go |
| [Механики](mechanics/) | Core loop, прогрессия, экономика и доказательства того, что механика работает |
| [Аналитика](analytics/) | Сравнения игр и рынков, метрики, источники и ограничения |

Начните с копии `TEMPLATE.md` нужного раздела. Для каждой цифры указывайте источник, дату, платформу и регион. Отделяйте факты от оценок и гипотез; помечайте данные старше 24 месяцев. Высокие метрики игры сами по себе не доказывают эффект отдельной механики.

Репозиторий публичный: не добавляйте приватную телеметрию, персональные данные, ключи и чужие материалы без разрешения.
