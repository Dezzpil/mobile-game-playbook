# A — «Ночная смена»: action survivor

- Статус / дата: гипотеза, 2026-11-18. Сроки, бюджеты и пороги — плановые оценки, не рыночные нормы. Общая программа: [analytics/rustore-genre-experiments.md](../analytics/rustore-genre-experiments.md).
- Аудитория и гипотеза: игроку интересен короткий забег, где слабый персонаж становится сильным через понятные сочетания усилений.
- Референс, сигнал спроса и аналоги: Survivor.io (мобильная подача, progression), Vampire Survivors (комбинации оружия), Brotato (читаемость волн). Премия RuStore 2026: Duck Survival, «Штурм Зомби». Актуальные метрики и насыщенность в РФ — проверить отдельно.
- Core loop: начать смену → двигаться/уклоняться → собирать детали → выбрать 1 из 3 усилений → пережить финальную волну/босса → постоянное улучшение → следующий забег. Портрет, один палец, автоатака. Первый забег ~90 с, далее 4–6 мин. Поражение сохраняет часть материалов. Сеттинг: ночной смотритель промгородка против механического хлама; оригинальные ассеты.
- MVP: 1 арена, 1 персонаж, 3 оружия, 5 врагов + босс, 12 усилений, 3 постоянных улучшения, 1 открываемая вариация оружия. Не включать: биомы, коллекцию героев, редкость снаряжения, PvP, сезоны. Godot 4, 2D, Compatibility renderer. 60–100 ч на вертикальный срез + 40–80 ч на retention-билд.
- Экономика и монетизация: одна валюта (детали), три ветки улучшений с видимым эффектом, без энергии и платного рандома. Rewarded: одно продолжение за забег (отказ = обычный финиш); отдельным тестом — бонус к материалам. IAP: пакет поддержки с косметикой 149–299 ₽. Первый оффер — после завершённого цикла, не по таймеру.
- Риски: бой скучен без сотен врагов; непонятна причина смерти (экран причины); усиления меняют только цифры; производительность на слабом Android (профилировать макс. волну); мета подменяет мастерство.
- События: run_start, weapon_selected, upgrade_offered, upgrade_selected, damage_taken (агрегат), run_end (длительность, причина, сборка, урон, убийства, fps), meta_upgrade, revive_offered, revive_result.
- Go/no-go: на 8–12 тестерах — управление понятно без объяснений, ≥половины сами начинают второй забег (качественный ориентир). Платная когорта: D1 ≥30%, D7 ≥8%. Стоп, если после одной содержательной переделки боя повторять забег не хочется.
- Оценки (1–5): спрос 4 / конкуренция 3 / соло 4 / монетизация 4 / риск 3. Приоритет 1.
- Открытые вопросы: насыщенность survivor-жанра в RuStore, CPI в VK Ads/Яндекс.
