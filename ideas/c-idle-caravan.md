# C — «Караван: пограничье»: idle squad RPG

- Статус / дата: гипотеза, 2026-11-18. Сроки, бюджеты и пороги — плановые оценки, не рыночные нормы. Общая программа: [analytics/rustore-genre-experiments.md](../analytics/rustore-genre-experiments.md).
- Аудитория и гипотеза: игроку интересно собирать небольшой отряд, менять состав под препятствие и возвращаться за накопленным.
- Референс: The Tower (idle progression), AFK Arena (роли), Melvor Idle (ясный долгий прогресс). Масштаб, gacha и live-ops не воспроизводим.
- Core loop: забрать ресурсы → выбрать маршрут и отряд → короткий бой → понять причину поражения → сменить состав/улучшение → продвинуться → оставить караван работать. Решение игрока должно менять результат.
- MVP: 3 места в отряде, 4 героя (защитник, стрелок, лекарь, пробивающий броню) с одним активным эффектом, 20–30 боевых узлов, 4 врага + босс, 3 слота снаряжения, офлайн-награда с потолком, 1 выбор маршрута. Без PvP, гильдий, серверной экономики. Статичные иллюстрации. 80–130 ч срез + 60–100 ч retention-билд — не самый дешёвый вариант.
- Экономика и монетизация: золото — уровни, материалы — снаряжение, без premium-валюты на тесте. Офлайн-доход от достигнутой зоны, потолок 8 ч (параметр теста). Rewarded: бонус к сбору награды с лимитом частоты. IAP: оформление каравана; функции удобства — только если базовый UI не урезан намеренно. Не продавать обязательных героев.
- Против «таблицы с кнопками»: после поражения показать причину (защитник погиб до лечения, броня выдержала атаки, лекарь не успевал) и дать сразу перепробовать без ожидания.
- Риски: всё решает уровень силы (один бой должен решаться сменой состава); заход только за сундуком; экономика ломается через сутки (табличная симуляция заранее); перевод часов (ограничение офлайн-начисления); баланс требует постоянного контента.
- События: offline_reward_claim, squad_changed, route_selected, battle_start, battle_end, hero_upgrade, equipment_upgrade, retry_after_loss. Ключевая метрика — доля, меняющих решение после поражения.
- Go/no-go: тестеры понимают роли и осознанно их используют; сессия не заканчивается сбором золота. Платная когорта: D1 ≥30%, D7 ≥10%. Стоп, если единственная стратегия — «подождать и купить уровень».
- Оценки (1–5): спрос 3 / конкуренция 4 / соло 4 / монетизация 3 / риск 3. Приоритет 3, контрольный эксперимент.
- Открытые вопросы: idle-аналоги в RuStore, защита офлайн-прогресса без сервера.
